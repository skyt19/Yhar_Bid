# Yhar_Bid
Yhar Bid is an application belonging to users to create an appointment, meetings, etc., by using AI LLM to motivated users, notifications with sound, has tracker to know how this user doing like snoozing, reason.


# How this system works;

if users set up the reminders on our apps. When users get the notification user might take a picture of places or works that users settings on so apps will use a LLM to recognise what type of picture is. Is that picture match the title of reminders. If yes the reminders will turn-off the notification. If not apps will stated as on-going or unfinished work. After that if none picture provices apps will stated as incomplete work the send to LLMs to genenrate motivated quotes, soft insult users or etc., based on their modes on first set-up like: soft, hard, extreme, your friend, your mom.
